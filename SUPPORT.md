# Support

## Community Support

If you need help with this project, please use the following resources:

1. **Documentation**: Check our [README](README.md) for setup and usage instructions.
2. **Issue Tracker**: Search for existing issues or open a new one in our [GitHub Issues](https://github.com/REChain-Network-Solutions/Core/issues).
3. **Discussions**: Join our [GitHub Discussions](https://github.com/REChain-Network-Solutions/Core/discussions) to ask questions and share ideas.
